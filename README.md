Robot Mobile Omnidirectionnel à Roues Mecanum contrôlé par Bluetooth avec flux vidéo ESP32-CAM
Présentation
Ce dépôt présente la conception et la réalisation d'un robot mobile omnidirectionnel à roues Mecanum, contrôlé par Bluetooth et équipé d'une ESP32-CAM pour la transmission vidéo en temps réel.
Fonctionnalités
- Déplacement omnidirectionnel
- Commande Bluetooth
- Suivi automatique
- Évitement d'obstacles
- Flux vidéo en temps réel avec ESP32-CAM
Contenu du dépôt
- Code Arduino du robot
- Code ESP32-CAM
- Images de la réalisation
- Vidéos de démonstration
